# Case Study

GlobalLaunch Studio explores how AI agents can scale product marketing without losing message consistency. I modeled seller education as a five-stage journey and encoded six specialized agent skills. Each skill contains a product-marketing objective, inputs, required messages, guardrails, examples, and an output schema.

The system routes bilingual seller questions, retrieves relevant product knowledge, generates a structured seller-education response, and evaluates the result for grounding, claim safety, CTA completeness, and journey fit. A labeled 24-case evaluation set makes the demo measurable without inventing commercial outcomes.

The v2 architecture intentionally separates product messaging, knowledge, agent skills, routing, generation, evaluation, and presentation so the workflow is easier to extend and explain in an interview.
