# VS Code quick start

1. Clone or download the repository.
2. Open the `global-launch-studio` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run `npm run demo`.
5. Open `http://127.0.0.1:4173`.

No `npm install` is required because the demo uses only Node.js built-in modules.

Useful commands:
- `npm test` — automated tests
- `npm run eval` — labeled agent evaluation
- `npm run check` — JavaScript syntax validation
